# v0.2.0 — Motion, Recovery and Complete Windows Delivery

这一版把大肥鱼从“能运行的桌宠”补成了可以长期使用的完整个人项目：动作更连贯、互动有部位差异、状态不会轻易丢失，并具备正式安装和升级闭环。

## 动作与互动

- 18 个运行时动作；左右各自使用独立四帧走路素材，不再镜像翻转配饰。
- 新增左右起步/停步、入睡/醒来、三帧进食和四帧尾巴反应。
- 脸、头、身体、尾巴分区命中；支持长按摸头、连续戳、连续投喂与快慢拖拽差异。
- 气泡不再立即打断刚触发的互动动作。

## 生命感与语料

- 470 条本地台词，包含四种人格、三段关系、首次见面、异常恢复、落地、窗口丢失、重复互动和社区梗。
- 微动作、完整活动和主动说话分别调度，减少长期待机时的忙乱与重复。

## 完整性

- 30 秒状态快照、配置/状态备份、15 秒会话心跳、轮转日志和异常报告。
- 连续两次异常退出后自动进入不覆盖原设置的安全模式。
- Inno Setup 当前用户安装、中文安装流程、开始菜单与可选桌面快捷方式。
- GitHub Releases 每日版本检查、安装包 SHA-256 校验、用户确认后覆盖安装并重启。
- 安装、运行、干净退出和卸载均已在 Windows 实机烟雾测试中通过。

- 便携压缩包：`DS-Local-Pet-v0.2.0-win-x64.zip`
