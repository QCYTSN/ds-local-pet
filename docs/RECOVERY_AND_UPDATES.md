# 恢复与更新设计

## 目标边界

这套机制只解决个人桌宠长期使用时最实际的完整性问题：异常后不丢状态、坏配置可回退、连续失败不会无限循环、普通用户可以安装并稳定升级。它不引入账号、遥测、云端 Dashboard、后台服务或模型调用。

## 用户数据

安装版把所有可写数据放在 `%LOCALAPPDATA%\DaFeiYuDesktopPet`：

```text
config.json / config.json.bak
pet_state.json / pet_state.json.bak
session_recovery.json
logs/dafeiyu.log(.1-.3)
logs/crashes/crash-*.log
updates/DS-Local-Pet-Setup-v*.exe
```

源码运行继续使用仓库根目录，测试和便携开发流程不变。`DAFEIYU_DATA_DIR` 只用于隔离测试或高级用户显式改写位置。

## 崩溃恢复

1. 启动时原子写入活动会话标记，并每 15 秒更新心跳。
2. 位置、配置和关系状态每 30 秒保存一次，正常退出前再保存一次；主 JSON 更新前保留 `.bak`。
3. 下次启动若发现上一会话仍为活动状态，则视为一次异常退出并恢复上次持久化状态。
4. 连续两次异常退出后，本次启动启用安全模式：静止、关闭环境感知、关闭窗口表面落脚、减少动态。
5. 安全模式是运行时覆盖，不写回用户原设置；一次正常退出后异常计数清零。
6. 未处理异常写入独立诊断文件。主日志轮转上限为 1 MB × 4，避免无限增长。

Windows Restart Manager 注册仅用于安装更新后的重启，不要求系统在崩溃或卡死时自动拉起进程；这样不会把重复崩溃变成高速重启循环。

## 安装程序

- Inno Setup 当前用户安装，默认不需要管理员权限。
- 固定 AppId 和固定 `DaFeiYuDesktopPet.exe` 路径支持覆盖升级。
- 提供开始菜单快捷方式及可选桌面快捷方式。
- 更新时允许安装器关闭当前进程并在完成后重新启动。
- 卸载只删除程序文件，保留用户状态和诊断记录。

## 自动更新

1. 安装版每天至多检查一次 `QCYTSN/ds-local-pet` 的 latest release；源码运行不会自动联网。
2. 版本号按三段语义版本进行数值比较。
3. 只接受与 Release 版本严格同名的唯一 Windows 安装包。
4. 下载地址必须属于 `https://github.com/`，Release 资产必须带有效的 `sha256:` 摘要。
5. 下载先写入 `.part`，完整哈希匹配后才原子替换为正式安装包；失败时删除临时文件。
6. 下载完成后询问用户是否安装，不会静默替换正在运行的程序。

版本检查只发送标准 HTTPS 请求头、应用名和当前版本，不发送环境感知、关系状态或台词记录。
