# Motion 2.0 prompt set

All four assets used the built-in ImageGen tool with the approved side walk sheet and/or front action masters as identity references. Each prompt required a perfectly flat `#00ff00` background, equal sprite cells, fixed scale and baseline, no text, watermark, external hand, shadow or extra limbs.

1. **Right walk** — exact same DaFeiYu character, true right-facing 2×2 four-phase gait, not a naive mirror; preserve permanent anatomical accessory placement and whale-apron orientation.
2. **Locomotion transitions** — exact same character in a 3×2 sheet; left and right rows each contain neutral side stand, start anticipation and braking/settling pose.
3. **Daily transitions** — exact same character in a 3×2 sheet; top row yawns, lowers with the whale pillow and sleeps; bottom row notices a blue fish snack, bites and finishes satisfied.
4. **Tail reaction** — exact same character in a 2×2 sequence; neutral, surprised tail flick, mildly annoyed glance toward the tail and recovery, with no external hand or impact icon.
